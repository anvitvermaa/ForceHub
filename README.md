## What is ForceHub?

ForceHub automatically pushes every **Accepted** Codeforces submission to your GitHub repository — in real time.

**🚀 The only extension that backfills past solutions.** No other tool does this.

## Features

- ⚡ **Real-time sync** — every new AC is committed to GitHub instantly
- 📦 **Backfill** — push ALL your historical Accepted solutions in one click
- 📊 **Analytics Dashboard** — streaks, ratings, language breakdown, solve heatmap
- 🔒 **Secure** — credentials stored locally, never sent to third parties

## Installation

1. Clone this repo
2. Open `chrome://extensions` → Enable Developer Mode
3. Click **Load unpacked** → select the `extension/` folder
4. Click the ForceHub icon and follow the setup steps

## Setup

You'll need:
- A **Codeforces** API Key + Secret ([generate here](https://codeforces.com/settings/api))
- A **GitHub** Personal Access Token with `repo` scope ([generate here](https://github.com/settings/tokens))
- Your GitHub username and target repository name
