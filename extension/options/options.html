01 — Verify Codeforces account
Generate an API key + secret at codeforces.com/settings/api (click Add API key). This proves you own the account — not just that the handle exists.

Your credentials are stored only on this device and sent nowhere except directly to codeforces.com as a cryptographic signature.
02 — Connect GitHub
ForceHub requests only the repo OAuth scope — the minimum needed to create commits. Your token is stored locally and only sent to api.github.com.
03 — Choose a repository
Pick an existing repo or create a new one. ForceHub will push your solutions here as commits.

✓ ForceHub is active
Syncing → every 30 seconds. Solve something on Codeforces and the commit will appear automatically.
